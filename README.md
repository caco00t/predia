# Predia

Página de prelanzamiento para validar interés en evaluaciones preliminares de terrenos para proyectos solares en Colombia.

Los registros se completan en Google Forms. Este repositorio no contiene respuestas, claves ni enlaces privados a la hoja de seguimiento. No se reciben pagos ni se generan análisis.

Publicación estática: `index.html` en la raíz; GitHub Pages desde la rama `main`, carpeta `/ (root)`.
